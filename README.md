# 🚀 Celebal Technologies – Machine Learning Foundation Assignments

This repository contains all weekly assignments completed during the **Machine Learning Foundation Program** as part of my **Data Scientist Internship at Celebal Technologies**.

# 📚 Weekly Assignments

| Week | Project | Topics Covered |
|------|---------|----------------|
| **Week 1** | Python Fundamentals | Python Programming, NumPy, Pandas, Data Analysis Fundamentals |
| **Week 2** | Tesla Deliveries Analysis & Forecasting | Exploratory Data Analysis (EDA), Feature Engineering, Regression Models, Time Series Analysis |
| **Week 3** | Country Clustering Analysis | Unsupervised Learning, K-Means Clustering, DBSCAN, Principal Component Analysis (PCA), Data Visualization |
| **Week 4** | CIFAR-10 Image Classification | Artificial Neural Networks (ANN), Convolutional Neural Networks (CNN), Image Classification, Computer Vision |
| **Week 5** | Text Generation using RNN, LSTM & GRU | Natural Language Processing (NLP), Sequence Modeling, Recurrent Neural Networks, Deep Learning |
| **Week 6** | Denoising Autoencoder using MNIST | Autoencoders, Image Denoising, Encoder-Decoder Architecture, Image Reconstruction, Computer Vision |
| **Week 7** | Retrieval-Augmented Generation (RAG) | Document Processing, Text Chunking, Sentence Embeddings, FAISS Vector Database, Semantic Search, Large Language Models (LLMs), Document Question Answering |
| **Week 8** | Single AI Agent | AI Agents, Intent Recognition, Tool Routing, Modular Programming, JSON Responses, Interactive AI Systems |
